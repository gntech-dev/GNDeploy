# Historial

## 0.2.1 - Instalador GitHub

Corrige la lectura de SHA256SUMS cuando GitHub sirve assets como application/octet-stream. Agrega prueba del flujo de instalacion GitHub y limites de espera de red. La descarga publica de 0.2.0 no completaba la verificacion; use 0.2.1.

## 0.2.0 - Distribucion publica experimental

Modulo instalable desde un ZIP de GitHub, versiones separadas fuera de OneDrive, verificacion SHA-256, comandos de entrada y construccion, licencia GPL-3.0-only, empaquetado con lista permitida y workflows de pruebas/release.

Basado en el runtime r12: centro de utilidades, SHA-256, consultas de unidades/dispositivos/red y carga INF de sesion. La referencia r12 aprobo 29 comprobaciones de menus en Hyper-V sin instalar Windows. Las pruebas fisicas pendientes no se consideran aprobadas por el empaquetado.

## Runtime r11

Cabecera de pasos, colores y controles Salir/Reiniciar protegidos; 24 comprobaciones de menus en Hyper-V.

## Runtime r10

Asistente guiado, revision previa, descargas reanudables, errores accionables y resultado exportable; 22 comprobaciones de menus en Hyper-V.
